# Sales Workflow Portfolio

A portfolio of AI-assisted sales workflow work, focused on the reasoning behind qualification, research and proposal decisions. This repository contains public documentation and sanitised examples only. The working implementations remain private.

| Project | What it demonstrates | Verified status |
|---|---|---|
| [Commercial Intelligence Outbound Prospecting Engine](commercial-intelligence/README.md) | Source-backed account research, counterevidence and explicit holds | Earlier bounded flow live-tested; adaptive extension mock-tested |
| [LinkedIn Outbound Workflow — Reference Design Review](linkedin-outbound/README.md) | Audience-to-message workflow structure and an honest implementation audit | Reference found; authorship, customisation and execution unverified |
| [Review-First Proposal-Writing Workflow](proposal-writing/README.md) | Discovery-to-proposal drafting with editable review and approval-sensitive terms | Live API integration tests with fictional data retained |

## The reasoning behind the work

- How source evidence changes a sales recommendation.
- Why missing information can lead to a hold rather than a forced opportunity.
- How a proposal review step protects scope and commercial terms.
- How verified results are separated from intended benefits and unfinished work.

The goal is to show judgment and verified progress without sharing a build recipe. Each project includes a high-level diagram, a clearly labelled mock output and a short walkthrough script. The LinkedIn reference is included for transparency, not as a claim of completed original work.

## Evidence and privacy

Status reviewed on 5 November 2026 against private project files, retained test artefacts, a read-only local workflow inventory and connected Drive material. No new live workflow or paid API test was performed for this showcase review. Historical timings describe individual tests, not typical performance or sales ROI. The source exports, code, detailed prompts, execution records, account links and real prospect data are deliberately absent.
